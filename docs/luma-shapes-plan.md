# แผน Luma Shapes

เพิ่มอัลกอริทึมที่อ่านความสว่าง ณ ศูนย์กลางแต่ละเซลล์ แล้วเลือกชุดรูปทรงตามช่วง 0–255 ตามภาพอ้างอิง ใช้ระบบภาพ วิดีโอ เลเยอร์ เอฟเฟกต์ และการส่งออกเดิม

1. [x] สร้างโมเดล 2–12 ช่วงที่ต่อกันครบ 0–255 ตรวจ JSON รูปทรง สี ขนาด และขอบเขต พร้อมบันทึกใน preset / undo / share / layer
2. [x] เพิ่ม GPU shader สำหรับ Empty, Circle, Square, Diamond, Line, Cross และ Ring พร้อมพื้นหลัง ขนาดเซลล์ มุม และ feather แบบ Ordered / Scatter
3. [x] ทำแผง Shape set (Halftone Dots / Geometric / Lines), แถบช่วงความสว่าง, เลือกช่วงเพื่อแก้ไขสี ขนาด และขอบบน, Split band / Distribute / Reverse / Remove และ JSON import / export
4. [x] เพิ่มคำแปลไทยและคำอธิบายการใช้งาน
5. [x] ทดสอบโมเดลและการโหลดค่าที่ผิด, รัน tests / typecheck / build / lint และตรวจ UI กับ GPU ในเบราว์เซอร์

ขอบเขต: ฟีเจอร์ที่สังเกตได้จากภาพ ไม่อ้างว่าพฤติกรรมตรงกับเครื่องมืออ้างอิงทุกจุด; การส่งออกใช้ pipeline เดิม (SVG แบบ pixel runs) และ Save preset ใช้แผง Presets เดิม

ผลตรวจ (2026-10-22): tests 449 ข้อผ่าน; TypeScript / production build / lint ผ่าน ตรวจเบราว์เซอร์ด้วยภาพตัวอย่างจริง: ปรับขนาดและขอบบนของช่วง, เปลี่ยนชุดเรขาคณิต, ปรับ feather ทั้ง Ordered / Scatter, แบ่งช่วง, กระจายเท่ากัน, กลับลำดับ และลบช่วงสุดท้ายโดยขอบยังจบที่ 255; รีโหลดแล้วยังคงค่าที่บันทึก และตรวจคำแปลไทย ไม่มี console / WebGL error ระหว่างตรวจ การเล่นวิดีโอและไฟล์แอนิเมชันใช้ pipeline ร่วมเดิม ยังไม่ได้ตรวจแบบ end-to-end เพิ่มในรอบนี้

## เพิ่มเติม: แถบลากและรูปทรงจากภาพ (2026-10-22)

- [x] แถบไล่ความสว่างพร้อมรูปตัวอย่างและจุดแบ่งที่ลากได้ รองรับ pointer capture สำหรับเมาส์/สัมผัส และปุ่มลูกศร / Shift / Home / End จุดแบ่งไม่ข้ามกัน
- [x] ตัวเลื่อน Band width ปรับความกว้างช่วงที่เลือก รวมถึงช่วงสุดท้ายโดยเลื่อนขอบซ้าย
- [x] อัปโหลดภาพรายช่วง รองรับ PNG / JPEG / WebP / GIF / BMP / AVIF ไม่เกิน 10 MB ปรับพอดีช่อง RGBA 64×64 เก็บสัดส่วนและ alpha; สีเริ่มต้นขาวเพื่อคงสีภาพ สามารถปรับสีเพื่อ tint ได้
- [x] ภาพฝังอยู่ใน JSON ของช่วง ติดไปกับ import/export, preset, layer, undo และ share link; ใช้ texture atlas และอัปโหลดใหม่เมื่อรูปหรืออันดับเปลี่ยนเท่านั้น
- [x] ขยายตัวอ่าน JSON ให้รับชุดรูปครบ 12 ช่วง และแก้การสร้าง share link ให้รองรับข้อมูลขนาดใหญ่โดยไม่ใช้ spread เป็นอาร์กิวเมนต์
- [x] tests 453 ข้อ / build / lint ผ่าน ตรวจจริง: ลากจุดแบ่งด้วยเมาส์, ปุ่มลูกศรและ End, ขอบไม่ข้ามกัน, ปรับช่วงสุดท้าย, อัปโหลด PNG โปร่งใสที่มีสีไม่สมมาตร, ตรวจสัดส่วน/ทิศทางภาพ, ส่งออก JSON แล้วนำกลับเข้า, รีโหลดแล้วยังมีภาพอยู่ และส่งออก PNG พร้อมรูปอัปโหลดได้ ไม่มี console / WebGL error

ข้อจำกัด: ภาพรูปทรงเป็นช่อง 64×64 และเป็นภาพนิ่ง; SVG แบบ pixel runs ยังอยู่ภายใต้ข้อจำกัดจำนวนสีเดิม ส่วน PNG เก็บสีภาพอัปโหลดได้ครบ
